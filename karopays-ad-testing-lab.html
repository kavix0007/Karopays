Security: Ad code is third-party JavaScript. It runs inside a sandboxed preview frame, not in this tester page. Some providers may require cookies, storage, popups, or top-level page access; those formats may not fully work inside the sandbox. Only paste code from a network you trust.

2. How to use

  1. Choose the network name and format.
  2. Copy the full publisher tag from your ad network dashboard.
  3. Paste it above and select Run ad preview.
  4. Wait a few seconds for the provider to load the ad.

For smartlinks/direct links, paste the URL and use the open-link option in the preview rather than expecting a banner to appear.
